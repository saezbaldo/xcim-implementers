# XCIM implementation matrix

This matrix is intentionally evidence-based. A sandbox, logo or private demo
does not count as independent interoperability.

| Entry | Role | Status | Evidence |
|---|---|---|---|
| Emabled reference issuer | Issuer | Operational sandbox | [emabled.com](https://emabled.com/) |
| Independent sender | Sending | Seeking first cohort | No report published |
| Independent receiver | Receiving | Seeking first cohort | No report published |
| Paired interoperability window | Sender + receiver | Not started | Requires two independent reports |

The machine-readable version is published at
[xcim.net/interop-matrix.json](https://xcim.net/interop-matrix.json). The
current source-drop commit is `3067979`.
